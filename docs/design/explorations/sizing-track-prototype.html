Ratio is primary, dollars secondary. You remember a villain's bet as "about two-thirds pot", not as $68 — so the unit you match against is shown largest. It switches per spot: % of pot postflop, × bb for a preflop open, × the last raise for a 3-bet.

All-in is a latch, not a slider position. It is categorical — that seat has no further decisions, though the hand continues for everyone else — so it sits past a gap rather than being the largest number on a continuum.

An interrupted gesture records nothing. If the browser or OS steals the pointer mid-drag it is logged as interrupted, never committed. The counter above tracks how often that happens.
